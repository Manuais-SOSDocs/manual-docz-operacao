# Novidades da Versão Publicada em 11/11/2026.

Esta versão reúne melhorias na configuração dos projetos, no acompanhamento do armazenamento e na personalização de espelhos e relatórios, além de ajustes nas integrações e nas consultas do Dashboard Sentinela.

### ↘️ Configurações do sistema

{% columns %}
{% column %}
#### 🔐 Gerenciamento das configurações por projeto&#xD;

A regra “Gerenciar” em Projetos passa a permitir a visualização e edição de suas configrações, além da criação e edição de campos e formulários. O acesso respeita a autorização concedida ao usuário em cada projeto.
{% endcolumn %}

{% column %}
#### 🔄 Configuração de passagem obrigatória&#xD;

Possibilidade de definir Etapas Documentais e Status da Gestão Documental obrigatórios, considerando a sequência do fluxo. A entrega inclui um serviço de validação das transições.
{% endcolumn %}
{% endcolumns %}

### ↘️ Gestão Documental

{% columns %}
{% column %}
#### 📋 Padronização de Etapas Documentais e Status&#xD;

Os cadastros passam a utilizar uma seleção pesquisável com nomenclaturas existentes nos Domínios do DocZ. A melhoria substitui a digitação livre, reduzindo diferenças de escrita e promovendo a padronização dos termos.
{% endcolumn %}

{% column %}
#### ⚙️ Personalização dos campos dos Espelhos Personalizados&#xD;

Configuração individual das propriedades de exibição e formatação dos campos pelo ícone de engrenagem. A prévia dinâmica facilita a conferência dos ajustes, e as alterações são registradas na trilha de auditoria.
{% endcolumn %}
{% endcolumns %}

### ↘️ Integrações & Comunicações

{% columns %}
{% column %}
#### 🔗 Ajustes na integração SEI/ANM&#xD;

A automação permite enviar novos volumes mesmo quando volumes anteriores do mesmo processo estiverem na etapa “FINALIZADO”. Também foi tratado o avanço de “ASSINADO” para “CONCLUÍDO” após a integração.
{% endcolumn %}

{% column %}
#### 📧 Orientação no compartilhamento de documentos&#xD;

Quando um e-mail é digitado sem ser incluído na lista de destinatários, o sistema orienta o usuário a clicar no botão “+” antes de compartilhar, tornando mais claro o procedimento para concluir o envio.
{% endcolumn %}
{% endcolumns %}

### ↘️ Módulo Storage

{% columns %}
{% column %}
#### 📊 Nova tela de consulta de Storage&#xD;

Consulta da ocupação por cliente e projeto com melhorias de desempenho, filtros, indicadores e totalizadores. A tela apresenta a referência de atualização dos dados e permite solicitar sua atualização manual, respeitando as permissões de acesso. O Repositório Físico mantém os dados da última apuração disponível.
{% endcolumn %}

{% column %}
#### 📑 Relatório detalhado de Storage&#xD;

Relatório configurável para analisar arquivos, metadados e Repositório Físico, com seleção de campos, filtros, agrupamentos e modelos reutilizáveis. A geração ocorre em segundo plano, com disponibilização em Excel na Central de Downloads e aviso por e-mail quando o arquivo estiver pronto.
{% endcolumn %}
{% endcolumns %}

### ↘️ Módulo Sentinela

{% columns %}
{% column %}
#### 🧹 Limpeza dos filtros no Dashboard Sentinela&#xD;

Correção do botão “Limpar Filtros”, permitindo remover os critérios preenchidos e preparar uma nova consulta.
{% endcolumn %}

{% column %}
#### 🎛️ Exibição das opções de Situação Gerencial&#xD;

Correção da lista do campo “Situação Gerencial” para apresentar todas as opções definidas na Configuração do Módulo Sentinela, conforme o cliente e o projeto selecionados.
{% endcolumn %}
{% endcolumns %}
