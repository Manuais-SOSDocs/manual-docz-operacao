# Espelho de caixa

A funcionalidade **Espelhos de Caixa** permite criar modelos personalizados para visualização e impressão das informações das caixas arquivadas no DocZ.

Por meio dessa funcionalidade, o administrador pode definir quais campos serão exibidos no espelho, como as informações serão organizadas e quais elementos visuais farão parte da impressão, sem necessidade de desenvolvimento ou customizações técnicas.

Cada projeto pode possuir seus próprios espelhos, adaptados às necessidades operacionais e aos padrões exigidos pelo cliente.

O acesso está disponível apenas para usuários com as permissões:

* Administrador;
* Configurar Espelho Personalizado.

{% hint style="info" %}
**O que é um Espelho de Caixa?**

O espelho é um modelo visual utilizado para apresentar informações de identificação e classificação de uma caixa arquivística.

Ele pode conter informações como:

* Classificação documental;
* Identificador da caixa;
* Código de barras;
* Prazo de guarda;
* Destinação final;
* Ano inicial e final;
* Campos personalizados do projeto;
* Logo da instituição.
{% endhint %}

#### Como Criar um Espelho de Caixa

{% stepper %}
{% step %}
Acesse:

**Projetos → Selecione o Projeto → Espelhos de Caixa**

A tela exibirá os espelhos já cadastrados para o projeto.

![](https://manualsosdocs.gitbook.io/adm-docz/~gitbook/image?url=https%3A%2F%2F2165951091-files.gitbook.io%2F%7E%2Ffiles%2Fv0%2Fb%2Fgitbook-x-prod.appspot.com%2Fo%2Fspaces%252FH2zBMzYHjbRsfnTeRGr3%252Fuploads%252FSSLDA779a4AWFXYS5pgJ%252Fimage.png%3Falt%3Dmedia%26token%3Db265e88d-1a06-4429-89d0-9dc3ea687afd\&width=768\&dpr=3\&quality=100\&sign=acddf3cc\&sv=2)
{% endstep %}

{% step %}
Clique em **Novo**.

O sistema abrirá a tela de configuração do espelho.

![](https://manualsosdocs.gitbook.io/adm-docz/~gitbook/image?url=https%3A%2F%2F2165951091-files.gitbook.io%2F%7E%2Ffiles%2Fv0%2Fb%2Fgitbook-x-prod.appspot.com%2Fo%2Fspaces%252FH2zBMzYHjbRsfnTeRGr3%252Fuploads%252Fr8uU0Zik9WVPmF9uuQwP%252Fimage.png%3Falt%3Dmedia%26token%3D57c7aafc-9825-4e56-828e-c4d903a4dce4\&width=768\&dpr=3\&quality=100\&sign=642f9626\&sv=2)
{% endstep %}

{% step %}
No bloco **Bloco Superior**, informe:

![](https://manualsosdocs.gitbook.io/adm-docz/~gitbook/image?url=https%3A%2F%2F2165951091-files.gitbook.io%2F%7E%2Ffiles%2Fv0%2Fb%2Fgitbook-x-prod.appspot.com%2Fo%2Fspaces%252FH2zBMzYHjbRsfnTeRGr3%252Fuploads%252FXBMuXfVjmlQPScjzFva6%252Fimage.png%3Falt%3Dmedia%26token%3Deef9ff8d-73be-4cc9-a42e-3164af0b6b1c\&width=768\&dpr=3\&quality=100\&sign=4d7cb2d7\&sv=2)

**Nome do Espelho**

Digite um nome que identifique facilmente o modelo.

Exemplos:

* Caixa RH
* Caixa Contratos
* Caixa Financeiro

**Modelo Base**

Selecione um dos modelos disponíveis.

Os modelos definem apenas a estrutura visual do espelho.

**Logo (Opcional)**

Caso deseje exibir a logo no espelho:

1.  Marque a opção **Incluir Logo**;

    <figure><img src="../../.gitbook/assets/image (3).png" alt=""><figcaption></figcaption></figure>
2. Clique em **Selecionar Logo**;
3. Escolha a imagem desejada.

Também é possível definir:

* Posição da logo (Esquerda, Centro ou Direita);
* Modo de exibição (Espaço padrão ou Preencher espaço).
{% endstep %}

{% step %}
Os campos exibidos no espelho são definidos em cada bloco da estrutura.

{% step %}
No bloco **Identificação**, escolha como o código de barras será gerado.

{% endstep %}

{% step %}
Durante a configuração, acompanhe a prévia exibida na área **Visualização**.

A prévia é atualizada conforme os campos são configurados.
{% endstep %}

{% step %}
Após concluir as configurações:

1. Revise a visualização;
2. Clique em **Salvar**.
{% endstep %}
{% endstepper %}

{% hint style="success" %}
O espelho ficará disponível para utilização nas impressões e consultas do projeto.
{% endhint %}

> **Dica:** Antes de disponibilizar um novo espelho para uso operacional, gere uma impressão de teste para validar:
>
> * Posicionamento dos campos;
> * Legibilidade das informações;
> * Exibição da logo;
> * Código de barras;
> * Informações de temporalidade.
