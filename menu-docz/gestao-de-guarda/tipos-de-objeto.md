# Tipos de Objeto

Esta tela corresponde ao **cadastro e gerenciamento de tipos de objetos** utilizados no sistema. Ela é dividida em duas seções principais:

* Grid 1 - "Cadastro de tipos de objetos:"
* Grid 2 - "Tipos de objetos cadastrados"

<figure><img src="../../.gitbook/assets/image (248).png" alt=""><figcaption></figcaption></figure>

### 📝**Para o cadastro de Tipos de Objetos:**

{% stepper %}
{% step %}
No formulário preencha os campos:

<kbd>Código</kbd>   <kbd>Descrição</kbd>   <kbd>Altura</kbd>   <kbd>Largura</kbd>   <kbd>Profundidade</kbd>    <kbd>Fator Conversão</kbd>
{% endstep %}

{% step %}
Marque as opções, se aplicável:

&#x20;<kbd>Objeto circular</kbd>   <kbd>Container</kbd>   <kbd>Permitir filhos</kbd>   <kbd>Permitir solicitação</kbd>
{% endstep %}

{% step %}
Se necessário, selecione um  <kbd>objeto pai</kbd>
{% endstep %}

{% step %}
Clique em  ![](<../../.gitbook/assets/image (249).png>)  para salvar
{% endstep %}
{% endstepper %}

{% hint style="success" %}
Pronto! O objeto foi cadastrado com sucesso.

Os resultados serão apresentados na grid **"Tipos de objetos cadastrados"** abaixo.
{% endhint %}

***

### 📦 **Gerenciamento dos objetos cadastrados:**

Na grid **"Tipos de Objetos Cadastrados"**, você pode **alterar** ou **excluir** itens já registrados:

<figure><img src="../../.gitbook/assets/image (250).png" alt=""><figcaption></figcaption></figure>

<details>

<summary>Para <strong>alterar as especificações do tipo de objeto</strong> ✍</summary>

1. Clique em **Editar**
2. O formulário acima será preenchido automaticamente com os dados do objeto
3. Faça as alterações desejadas.
4. Clique em ![](<../../.gitbook/assets/image (251).png>)

</details>

<details>

<summary>Para <strong>excluir</strong> o tipo de objeto 🗑</summary>

1. Clique em **Excluir**.
2. Uma mensagem de confirmação será exibida na tela.
3. Confirme para concluir a exclusão.

</details>
