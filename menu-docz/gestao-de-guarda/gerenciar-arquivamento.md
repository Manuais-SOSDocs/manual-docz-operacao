# Gerenciar Arquivamento

A tela **Gerenciar Arquivamento** permite agrupar documentos em lotes e acompanhar todo o processo de envio ao arquivo físico, desde a seleção dos objetos até a finalização da demanda.

<figure><img src="../../.gitbook/assets/image (262).png" alt=""><figcaption></figcaption></figure>

### 🗂️Para Criar um lote:

{% stepper %}
{% step %}
Digite ou **bipe a etiqueta** do objeto.

<figure><img src="../../.gitbook/assets/image (311).png" alt=""><figcaption></figcaption></figure>

_O campo "Último número bipado" mostrará o último documento lido via bipagem._
{% endstep %}

{% step %}
Os documentos serão listados na grid “Total de Objetos”.

<figure><img src="../../.gitbook/assets/image (312).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
Marque os documentos desejados clicando nas **checkboxes**.
{% endstep %}

{% step %}
Clique no botão ![](<../../.gitbook/assets/image (313).png>) .
{% endstep %}
{% endstepper %}

{% hint style="success" %}
O lote será exibido na grid abaixo “Total de Lotes”.
{% endhint %}

***

### 📦 Para distribuir um lote:

{% stepper %}
{% step %}
Selecione na grid “Total de Lotes” o(s) lote(s) com a checkbox.

<figure><img src="../../.gitbook/assets/image (314).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
Abaixo da grid escolha o usuário que receberá a demanda.

<figure><img src="../../.gitbook/assets/image (315).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
Clique em ![](<../../.gitbook/assets/image (316).png>) .
{% endstep %}
{% endstepper %}

{% hint style="success" %}
O lote foi distribuído.
{% endhint %}

***
