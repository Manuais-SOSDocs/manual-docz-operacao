# Tipos de Arquivo Documento

Esta tela permite cadastrar e gerenciar os tipos de documentos (tipologias) utilizados em um projeto, como processo, dossiê, formulário, entre outros.

<figure><img src="../../.gitbook/assets/image (344).png" alt=""><figcaption></figcaption></figure>

## 👁‍🗨 Como funciona:

### **1. Lista de Tipos de Arquivo (grid superior):**

Exibe todas as tipologias já cadastradas no sistema.

<table><thead><tr><th width="644">Ações disponíveis:</th></tr></thead><tbody><tr><td>✅ Editar uma tipologia existente.</td></tr><tr><td>❌ Excluir uma tipologia da lista.</td></tr></tbody></table>

### **2. Novo Tipo de Arquivo (grid inferior):**

Para cadastrar uma nova tipologia:

{% stepper %}
{% step %}
Preencha o campo **Descrição** com o nome do tipo documental (ex: Processo, Dossiê).
{% endstep %}

{% step %}
Clique em **Salvar** para adicionar a nova tipologia à lista.
{% endstep %}
{% endstepper %}

{% hint style="success" %}
**Ação concluída com sucesso.**
{% endhint %}
