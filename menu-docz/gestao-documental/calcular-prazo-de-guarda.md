# Calcular Prazo de Guarda

A funcionalidade **Calcular Prazo de Guarda** permite gerar listagens de documentos com seus respectivos prazos, conforme a Tabela de Temporalidade configurada para o projeto.

<figure><img src="../../.gitbook/assets/image (31) (1).png" alt=""><figcaption></figcaption></figure>

#### 📘 **Passo a passo – Calcular Prazo de Guarda**

{% stepper %}
{% step %}
**Selecione o projeto desejado** no campo _Projeto_.

<figure><img src="../../.gitbook/assets/image (477).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
No campo **Classificação**, selecione a opção **Classificação** configurada para o projeto.

<figure><img src="../../.gitbook/assets/image (478).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
No campo _Ano de Produção_, selecione o campo correspondente ao ano de criação/produção do objeto, que será utilizado como base para o cálculo do prazo de guarda.

Exemplos de metadados: _`Ano inicial`_  ou  _`Ano de produção`_

<figure><img src="../../.gitbook/assets/image (479).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
No campo **Destinação Final**, escolha se deseja gerar uma listagem de **Eliminação** ou **Guarda Permanente** e clique em <img src="../../.gitbook/assets/image (480).png" alt="" data-size="line">.

<figure><img src="../../.gitbook/assets/image (481).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
Os **resultados da pesquisa** serão exibidos na grade abaixo.

<figure><img src="../../.gitbook/assets/image (482).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
O usuário poderá **exportar o relatório em formato Excel ou PDF**, clicando nos botões localizados abaixo da grade.

<figure><img src="../../.gitbook/assets/image (483).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
Os relatórios em **Excel e PDF são gerados em segundo plano** e ficam disponíveis para download na [**Central de Downloads**](../relatorios/central-de-downloads.md).
{% endstep %}
{% endstepper %}

{% hint style="success" %}
Ação concluída
{% endhint %}
