# Projeto Etapa Indexação

Esta tela permite cadastrar novas etapas no fluxo de gestão documental de um projeto.

<figure><img src="../../.gitbook/assets/image (345).png" alt=""><figcaption></figcaption></figure>

> 🗑️ **Para excluir uma etapa:**\
> Na grid "Etapas Cadastradas", clique no ícone de **excluir** ao lado da etapa desejada.

### &#x20;<mark style="color:blue;background-color:blue;">➕</mark> **Como cadastrar uma nova etapa:**

{% stepper %}
{% step %}
Escreva o nome da etapa no campo indicado.
{% endstep %}

{% step %}
Selecione o projeto ao qual a etapa será vinculada.
{% endstep %}

{% step %}
Clique em <img src="../../.gitbook/assets/image (384).png" alt="" data-size="line"> (adicionar).
{% endstep %}
{% endstepper %}

{% hint style="success" %}
**A etapa será cadastrada e aparecerá automaticamente na grid abaixo.**
{% endhint %}
