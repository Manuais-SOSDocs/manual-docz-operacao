# Distribuir p/ Indexação

Esta tela tem como objetivo **organizar e automatizar a distribuição para indexação** entre os usuários do sistema. Ao centralizar essa operação, ela promove **mais controle, agilidade e rastreabilidade** em todo o processo de gestão documental — tanto para documentos físicos quanto digitais.

<figure><img src="../../.gitbook/assets/image (339).png" alt=""><figcaption></figcaption></figure>

#### 🧩 Como funciona?

{% stepper %}
{% step %}
**Selecione o projeto** (campo obrigatório).
{% endstep %}

{% step %}
**Configure os filtros** conforme necessário:

<sub><kbd>Identificador SOS: para busca direta.<kbd></sub> \
<sub><kbd>Status e Tipo de Objeto: para refinar os resultados.<kbd></sub> \
<sub><kbd>Arquivo Digital: escolha entre objetos com ou sem arquivo.<kbd></sub>\
<sub><kbd>Etapa de Indexação: defina a etapa atual dos objetos.<kbd></sub>
{% endstep %}

{% step %}
Clique em ![](<../../.gitbook/assets/image (230).png>) .
{% endstep %}

{% step %}
A lista será exibida com o total encontrado
{% endstep %}

{% step %}
Escolha o **usuário que receberá** os documentos.
{% endstep %}

{% step %}
Defina a **etapa de indexação de destino**.
{% endstep %}

{% step %}
Marque as opções, se necessário:

* ✅ **Atualizar Status** dos documentos automaticamente.
* ✅ **Distribuir Documentos Indexados** já processados.
{% endstep %}

{% step %}
Clique em ![](<../../.gitbook/assets/image (231).png>) .
{% endstep %}
{% endstepper %}

{% hint style="success" %}
**Ação concluída com sucesso!**
{% endhint %}
