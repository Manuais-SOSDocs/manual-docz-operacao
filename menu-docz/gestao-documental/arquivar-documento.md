# Arquivar Documento

Esta tela permite vincular documentos a caixas físicas já cadastradas no sistema, garantindo controle e rastreabilidade do acervo.

<figure><img src="../../.gitbook/assets/image (338).png" alt=""><figcaption></figcaption></figure>

### **🔄 Como funciona:**

{% stepper %}
{% step %}
**Digite ou bipar** o ID SOS do documento.
{% endstep %}

{% step %}
Em seguida, **bipar o código da etiqueta** (ID SOS) da caixa onde o documento será arquivado.

> _A caixa precisa estar previamente cadastrada no sistema._
{% endstep %}
{% endstepper %}

{% hint style="success" %}
O campo **“Último número bipado”** mostra o último ID lido (documento ou caixa), facilitando a conferência.
{% endhint %}
