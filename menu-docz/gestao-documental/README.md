# GESTÃO DOCUMENTAL

O módulo **Gestão Documental** reúne as funcionalidades responsáveis pelo controle do ciclo de vida dos documentos dentro do DocZ, desde sua inclusão e tratamento até a definição dos prazos de guarda e destinação final.

Por meio deste módulo é possível gerenciar processos como distribuição para indexação, digitalização, classificação documental, controle de status, cálculo de temporalidade e acompanhamento dos prazos arquivísticos.

Além das atividades operacionais, o módulo concentra recursos essenciais para a aplicação da **Tabela de Temporalidade**, garantindo que os documentos sejam gerenciados de acordo com as políticas de retenção, guarda e destinação definidas pela organização.
