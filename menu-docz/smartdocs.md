# SMARTDOCS

A funcionalidade SmartDocs permite ao administrador visualizar e acessar as instâncias SmartDocs habilitadas no ambiente DocZ.Nesta tela são apresentados os ambientes disponíveis vinculados ao usuário autenticado, contendo informações como:

* Cliente;
* Tenant;
* Organização vinculada;
* Opção de acesso à instância.

Por meio desta funcionalidade, o administrador pode gerenciar o acesso entre diferentes ambientes integrados ao sistema, facilitando a navegação e administração das instâncias habilitadas.🛈 O acesso ao módulo requer permissões específicas e autenticação nos ambientes integrados.

<summary><strong>Para quem utiliza o DocZ e o Smartdocs.</strong></summary>

👥 Integração e Criação Automática de Usuários via SSO

O SmartDocs oferece **integração direta com o DocZ**, permitindo que usuários logados sejam redirecionados automaticamente para o SmartDocs **sem precisar fazer um novo login**.

* **Primeiro acesso simplificado:** Ao utilizar o **SSO (Single Sign-On)**, o sistema realiza automaticamente o cadastro do usuário no SmartDocs, agilizando a autenticação e garantindo integração com outros sistemas corporativos.
* **Navegação fluida:** Usuários podem transitar entre DocZ e SmartDocs sem interrupções, tornando os fluxos de trabalho mais eficientes.

ℹ️ **Observação:** Essa funcionalidade requer configuração específica nos ambientes e está <mark style="color:blue;">disponível apenas para clientes que utilizam ambos os sistemas.</mark> Para habilitar, entre em contato com o suporte do Grupo SOSDocs via chamado.
