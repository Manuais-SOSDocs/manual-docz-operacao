# SOLICITAÇÕES

O módulo **Solicitações** é utilizado principalmente para acompanhamento, gerenciamento e controle das Ordens de Serviço (OS), além das funcionalidades específicas de **Solicitação de Implantação** e **Solicitação de Suprimentos**.

As solicitações operacionais de documentos, caixas e objetos documentais **não são abertas neste menu**. Elas são realizadas através da funcionalidade [**Pesquisa**](../pesquisar/), onde o usuário localiza os objetos desejados e, a partir do resultado da pesquisa, cria a Ordem de Serviço correspondente.
