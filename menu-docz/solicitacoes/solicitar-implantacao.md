# Solicitar Implantação

{% stepper %}
{% step %}
Na aba de **Implantação**, onde deverá preencher um formulário.

<figure><img src="https://manualsosdocs.gitbook.io/~gitbook/image?url=https%3A%2F%2F4270511437-files.gitbook.io%2F%7E%2Ffiles%2Fv0%2Fb%2Fgitbook-x-prod.appspot.com%2Fo%2Fspaces%252FTOkpktW1KcGIR73wpKDq%252Fuploads%252F6UFVvazMnb4YKetxYaCY%252Fimage.png%3Falt%3Dmedia%26token%3D8cc5a4ab-287c-456d-88d7-a7c0585c4ada&#x26;width=768&#x26;dpr=4&#x26;quality=100&#x26;sign=5b1e71c2&#x26;sv=2" alt=""><figcaption></figcaption></figure>

> 📝 **Preenchendo o formulário:**
>
> * **Unidade de Atendimento**: Selecione a unidade responsável pela guarda (ex: G2 - GUARDA CEILÂNDIA II/DF).
> * **Departamento**: Escolha o setor solicitante.
> * **Prioridade**: Defina a urgência da solicitação (Normal, Urgente, etc.).
> * **Data e Hora da Entrega**: Informe quando o item solicitado deverá ser entregue.
> * **Item**: Selecione o tipo de item desejado (ex: caixa, documento, suprimento).
> * **Descrição**: Detalhe o que está sendo solicitado (ex: "Caixa para acondicionar contratos de 2022").
> * **Quantidade**: Informe o número de unidades necessárias.
{% endstep %}

{% step %}
Após preencher os dados do item, clique no ícone ![](https://manualsosdocs.gitbook.io/~gitbook/image?url=https%3A%2F%2F4270511437-files.gitbook.io%2F%7E%2Ffiles%2Fv0%2Fb%2Fgitbook-x-prod.appspot.com%2Fo%2Fspaces%252FTOkpktW1KcGIR73wpKDq%252Fuploads%252FJZbowtXVaQn1oYPEEQpo%252Fimage.png%3Falt%3Dmedia%26token%3Dd4d6ecc4-684e-4cbe-bfda-e742549edf65\&width=300\&dpr=4\&quality=100\&sign=e905ed53\&sv=2) da coluna **Adicionar**.

<figure><img src="https://manualsosdocs.gitbook.io/~gitbook/image?url=https%3A%2F%2F4270511437-files.gitbook.io%2F%7E%2Ffiles%2Fv0%2Fb%2Fgitbook-x-prod.appspot.com%2Fo%2Fspaces%252FTOkpktW1KcGIR73wpKDq%252Fuploads%252FPYnnGLToLhqmtAKKChpu%252Fimage.png%3Falt%3Dmedia%26token%3Da4f37b35-0b48-49a2-a09c-1b0c3cc852c0&#x26;width=768&#x26;dpr=4&#x26;quality=100&#x26;sign=fc505582&#x26;sv=2" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
**Observação**: Se necessário, utilize o campo para informações adicionais (ex: localização, instruções específicas, etc.).
{% endstep %}

{% step %}
**👤 Deseja adicionar destinatários para acompanhar a O.S.?**

Se você quiser que outra pessoa receba notificações sobre a solicitação (como por e-mail ou WhatsApp), siga os passos abaixo:

{% stepper %}
{% step %}
Vá até a aba **Destinatário(s)**.

<figure><img src="https://manualsosdocs.gitbook.io/~gitbook/image?url=https%3A%2F%2F4270511437-files.gitbook.io%2F%7E%2Ffiles%2Fv0%2Fb%2Fgitbook-x-prod.appspot.com%2Fo%2Fspaces%252FTOkpktW1KcGIR73wpKDq%252Fuploads%252Fo2UEKBuGjiOmSULgALs1%252Fimage.png%3Falt%3Dmedia%26token%3Dc97deb31-ddad-4c7d-8f37-52e22a91f363&#x26;width=768&#x26;dpr=4&#x26;quality=100&#x26;sign=c00a23da&#x26;sv=2" alt=""><figcaption></figcaption></figure>


{% endstep %}

{% step %}
Preencha os campos:

`Nome completo` `E-mail` `Telefone`
{% endstep %}

{% step %}
Marque os meios pelos quais o destinatário será notificado

`E-mail` `WhatsApp` ou `SMS`
{% endstep %}

{% step %}
Clique no botão ![](https://manualsosdocs.gitbook.io/~gitbook/image?url=https%3A%2F%2F4270511437-files.gitbook.io%2F%7E%2Ffiles%2Fv0%2Fb%2Fgitbook-x-prod.appspot.com%2Fo%2Fspaces%252FTOkpktW1KcGIR73wpKDq%252Fuploads%252F4vSH21NAls5VvrT83P2J%252Fimage.png%3Falt%3Dmedia%26token%3D3bfb1e6c-c7e2-4b02-8c62-bcc47156251d\&width=300\&dpr=4\&quality=100\&sign=8ed8509a\&sv=2) para adicionar o destinatário à solicitação.
{% endstep %}
{% endstepper %}

{% hint style="info" %}
A lista dos destinatários será exibida abaixo, confirmando o cadastro.

Assim, todos os envolvidos serão informados automaticamente sobre o andamento da ordem de serviço.
{% endhint %}
{% endstep %}

{% step %}
Após preencher os campos, na aba **"Dados"** clique no botão ![](https://manualsosdocs.gitbook.io/~gitbook/image?url=https%3A%2F%2F4270511437-files.gitbook.io%2F%7E%2Ffiles%2Fv0%2Fb%2Fgitbook-x-prod.appspot.com%2Fo%2Fspaces%252FTOkpktW1KcGIR73wpKDq%252Fuploads%252FBx3JAbBUw2QxwnbL1WVN%252Fimage.png%3Falt%3Dmedia%26token%3D4ee3b448-5877-48f2-ab86-7d344157ca97\&width=300\&dpr=4\&quality=100\&sign=778b01c7\&sv=2) no canto inferior direito da tela.
{% endstep %}
{% endstepper %}

{% hint style="success" %}
**Pronto!** Sua solicitação foi enviada e todos os destinatários cadastrados receberão um e-mail.

📞 Caso tenha dúvidas, entre em contato com o suporte do Grupo Sos Docs.
{% endhint %}
