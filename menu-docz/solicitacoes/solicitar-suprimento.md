# Solicitar Suprimento

## Como solicitar suprimentos

{% stepper %}
{% step %}
No **menu lateral**, clique em **Solicitações**

<figure><img src="https://manualsosdocs.gitbook.io/~gitbook/image?url=https%3A%2F%2F4270511437-files.gitbook.io%2F%7E%2Ffiles%2Fv0%2Fb%2Fgitbook-x-prod.appspot.com%2Fo%2Fspaces%252FTOkpktW1KcGIR73wpKDq%252Fuploads%252FfUvXFzG1uTQhkP15mnqY%252Fimage.png%3Falt%3Dmedia%26token%3D7a4aa689-dc96-4004-b5ec-bee132294c1f&#x26;width=768&#x26;dpr=4&#x26;quality=100&#x26;sign=f1b9067&#x26;sv=2" alt=""><figcaption></figcaption></figure>


{% endstep %}

{% step %}
Em seguida, selecione a opção **Solicitar Suprimento**

<figure><img src="https://manualsosdocs.gitbook.io/~gitbook/image?url=https%3A%2F%2F4270511437-files.gitbook.io%2F%7E%2Ffiles%2Fv0%2Fb%2Fgitbook-x-prod.appspot.com%2Fo%2Fspaces%252FTOkpktW1KcGIR73wpKDq%252Fuploads%252FIDD1axPKB3wDRGWfrDgI%252Fimage.png%3Falt%3Dmedia%26token%3Da3dc5161-6312-4895-a25e-bc49b5b72697&#x26;width=768&#x26;dpr=4&#x26;quality=100&#x26;sign=b40b0e2&#x26;sv=2" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
Você será direcionado para a aba de **solicitação de suprimentos**, onde deverá preencher um formulário.

<figure><img src="https://manualsosdocs.gitbook.io/~gitbook/image?url=https%3A%2F%2F4270511437-files.gitbook.io%2F%7E%2Ffiles%2Fv0%2Fb%2Fgitbook-x-prod.appspot.com%2Fo%2Fspaces%252FTOkpktW1KcGIR73wpKDq%252Fuploads%252FeeUz4BjkUgc3fcwc5KDL%252Fimage.png%3Falt%3Dmedia%26token%3D00bb3b05-a4f1-4084-b039-d031ba69beda&#x26;width=768&#x26;dpr=4&#x26;quality=100&#x26;sign=c3efc6b6&#x26;sv=2" alt=""><figcaption></figcaption></figure>

<figure><img src="https://manualsosdocs.gitbook.io/~gitbook/image?url=https%3A%2F%2F4270511437-files.gitbook.io%2F%7E%2Ffiles%2Fv0%2Fb%2Fgitbook-x-prod.appspot.com%2Fo%2Fspaces%252FTOkpktW1KcGIR73wpKDq%252Fuploads%252F7JNGFyKY4qzwWClPuRMl%252Fimage.png%3Falt%3Dmedia%26token%3D7d64c6ac-1988-4a97-9ed1-6036ef2938c8&#x26;width=768&#x26;dpr=4&#x26;quality=100&#x26;sign=f3de8027&#x26;sv=2" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
**Preenchendo o formulário - Item:** escolha o insumo desejado. As opções disponíveis são:

`📦 Caixa 20kg sem Lacre` `📦 Caixa 20kg com Lacre` `📦 Caixa Box` `🎞️ Caixa Mídia` `🏷️ Etiqueta Documento` `🏷️ Etiqueta Caixa Box` `🏷️ Etiqueta Caixa 20Kg` `🏷️ Etiqueta de Controle de Produção` `🗺️ Mapa` `💿 Mídia` `💽 Mídia Especial` `📏 Papelão Ondulado Face Simples (metro)` `📦 Tubo para Mapa`

* **Descrição (opcional):** insira observações adicionais, se necessário.
* **Quantidade:** informe o número de unidades desejadas.

<figure><img src="https://manualsosdocs.gitbook.io/~gitbook/image?url=https%3A%2F%2F4270511437-files.gitbook.io%2F%7E%2Ffiles%2Fv0%2Fb%2Fgitbook-x-prod.appspot.com%2Fo%2Fspaces%252FTOkpktW1KcGIR73wpKDq%252Fuploads%252FRTcKGtcsDN7Tc2nxJSY0%252Fimage.png%3Falt%3Dmedia%26token%3D15472932-0953-448e-a6a1-5870b2b8d8e3&#x26;width=768&#x26;dpr=4&#x26;quality=100&#x26;sign=87bffbe4&#x26;sv=2" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
Após preencher os dados do item, clique no ícone **➕** da coluna **Adicionar**.

<figure><img src="https://manualsosdocs.gitbook.io/~gitbook/image?url=https%3A%2F%2F4270511437-files.gitbook.io%2F%7E%2Ffiles%2Fv0%2Fb%2Fgitbook-x-prod.appspot.com%2Fo%2Fspaces%252FTOkpktW1KcGIR73wpKDq%252Fuploads%252FPYnnGLToLhqmtAKKChpu%252Fimage.png%3Falt%3Dmedia%26token%3Da4f37b35-0b48-49a2-a09c-1b0c3cc852c0&#x26;width=768&#x26;dpr=4&#x26;quality=100&#x26;sign=fc505582&#x26;sv=2" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
Para finalizar, clique no botão ![](https://manualsosdocs.gitbook.io/~gitbook/image?url=https%3A%2F%2F4270511437-files.gitbook.io%2F%7E%2Ffiles%2Fv0%2Fb%2Fgitbook-x-prod.appspot.com%2Fo%2Fspaces%252FTOkpktW1KcGIR73wpKDq%252Fuploads%252FqqfeYcwf5BBLV5VDVt5v%252Fimage.png%3Falt%3Dmedia%26token%3D434b59d5-7952-4a92-8947-a40dfc7fa3a9\&width=300\&dpr=4\&quality=100\&sign=6ffbdb2e\&sv=2)
{% endstep %}
{% endstepper %}

{% hint style="success" %}
A solicitação será registrada como uma **Ordem de Serviço (OS)** no sistema e poderá ser acompanhada na aba de solicitações.

📞 Caso tenha dúvidas, entre em contato com o suporte do Grupo Sos Docs.
{% endhint %}
