# Grupos

A aba **Grupos** permite controlar o acesso dos usuários aos projetos, garantindo segurança e evitando acessos indevidos às informações dos clientes.

<figure><img src="../../.gitbook/assets/image (368).png" alt=""><figcaption></figcaption></figure>

### **➕ Criar um novo grupo**

{% stepper %}
{% step %}
Preencha o formulário com as informações do grupo e defina as permissões conforme a parametrização do projeto.

<div align="left"><figure><img src="../../.gitbook/assets/image (470).png" alt="" width="563"><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
No campo **"Selecione os usuários"**, escolha os usuários que farão parte do grupo e clique em **“+”**.

<div align="left"><figure><img src="../../.gitbook/assets/image (408).png" alt="" width="563"><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
Após adicionar os usuários, clique em <img src="../../.gitbook/assets/image (471).png" alt="" data-size="line">.
{% endstep %}
{% endstepper %}

{% hint style="success" %}
Pronto! O grupo foi criado com sucesso.
{% endhint %}

<details>

<summary><strong>👤 Para incluir um usuário em um grupo já existente</strong></summary>

1. Na grid da esquerda, selecione o grupo desejado.\
   O grupo será exibido na grid da direita com o título <mark style="color:red;">**\[Editando]**</mark>.
2. Vá até o campo **"Selecione os usuários"**.
3. Escolha o usuário a ser incluído e clique em **“+”**.
4. Clique em **Salvar** para confirmar a alteração.

{% hint style="success" %}
Usuário adicionado ao grupo com sucesso.
{% endhint %}

</details>
