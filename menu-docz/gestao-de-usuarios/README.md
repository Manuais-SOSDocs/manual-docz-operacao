# GESTÃO DE USUÁRIOS

O módulo **Gestão de Usuários** é responsável pelo controle de acesso ao DocZ, permitindo administrar usuários, grupos e permissões de forma centralizada.

Por meio deste módulo, os administradores definem quem pode acessar o sistema, quais funcionalidades estarão disponíveis para cada usuário e quais projetos ou clientes poderão ser visualizados.
