# Aba - Adicionar

A aba **Adicionar** é utilizada para incluir novos arquivos no objeto. Por meio dela, usuários autorizados podem realizar o upload de documentos, imagens, áudios, vídeos e outros formatos suportados pelo sistema.

Os arquivos podem ser adicionados selecionando-os manualmente no computador ou por meio do recurso de arrastar e soltar (drag and drop). Após a conclusão do upload, os arquivos passam a ficar disponíveis na aba **Arquivos**, onde poderão ser visualizados e gerenciados conforme as permissões do usuário.

{% hint style="info" %}
**Importante:** Para adicionar novos arquivos ao objeto, o usuário deve possuir a permissão **Adicionar Arquivos**.
{% endhint %}

<summary>Validação de Assinatura Digital</summary>

Durante o processo de upload, o sistema verifica automaticamente se o arquivo enviado possui uma assinatura digital incorporada.

Quando uma assinatura digital é identificada, o DocZ realiza uma validação antes de concluir a importação do documento, verificando aspectos como:

* Integridade da assinatura;
* Validade do certificado digital;
* Consistência das informações assinadas;
* Confiabilidade da assinatura digital.

Caso sejam encontradas inconsistências, como assinatura inválida, expirada, corrompida ou não confiável, o sistema exibirá uma mensagem informativa ao usuário.

**Mensagem exibida:**

<figure><img src="../../../../.gitbook/assets/image (563).png" alt=""><figcaption></figcaption></figure>

Nesse caso, o usuário poderá:

* **Prosseguir com a importação**, concluindo normalmente o upload do arquivo;
* **Cancelar a operação**, interrompendo o processo de importação.

{% hint style="info" %}
**Importante**

A existência de uma inconsistência na assinatura digital não impede obrigatoriamente a importação do documento. A decisão final de prosseguir ou cancelar a inclusão do arquivo fica a critério do usuário responsável pelo upload.

Para fins de rastreabilidade, o sistema registra:

* O resultado da validação da assinatura digital;
* A situação identificada (válida, inválida, expirada ou inconsistente);
* A decisão tomada pelo usuário durante a importação.
{% endhint %}
