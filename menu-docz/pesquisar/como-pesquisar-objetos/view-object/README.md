# View Object

**Como abrir os detalhes:**

{% stepper %}
{% step %}
Realize uma pesquisa e selecione o documento desejado.
{% endstep %}

{% step %}
Clique no ícone  ao lado do documento, para abrir os detalhes.

{% endstep %}
