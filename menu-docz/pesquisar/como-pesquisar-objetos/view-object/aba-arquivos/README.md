# Aba - Arquivos

A aba **Arquivos** permite visualizar todos os arquivos digitais vinculados ao objeto, sejam eles documentos, caixas ou outros tipos de registros cadastrados no sistema.

Além da visualização dos arquivos, esta aba disponibiliza informações técnicas e de controle, como nome do arquivo, data de inclusão, tamanho e **hash de integridade**, utilizado para validação e rastreabilidade do documento digital.

Dependendo das permissões atribuídas ao usuário, também é possível executar diversas ações sobre os arquivos, tais como:

* Visualizar arquivos;
* Realizar download;
* Editar informações;
* Assinar digitalmente;
* Substituir arquivos;
* Excluir arquivos;
* Gerenciar versões dos arquivos.

A visualização desta aba está condicionada à permissão de acesso a arquivos. Usuários que não possuírem essa permissão não terão acesso ao conteúdo da aba nem às ações relacionadas aos arquivos vinculados ao objeto.

<summary>🧾 <strong>Visualizando os dados do Arquivo</strong></summary>

Na tela de visualização de documentos, o sistema apresenta automaticamente os **dados** associados a cada arquivo. Essas informações ajudam a identificar e controlar o ciclo de vida dos documentos.

<sub>📌</sub> <sub>**Observação:**</sub> <sub>O acesso a esta aba depende do</sub> <sub>**perfil de permissões do usuário**</sub><sub>. Em caso de dúvidas, entre em contato com o</sub> <sub>**suporte técnico**</sub> <sub>ou com o</sub> <sub>**gerente responsável**</sub><sub>.</sub>

📌 **Os dados exibidos incluem:**

`Tipologia documental` `Autor` `Usuário responsável pelo upload` `Versão do documento` `Tamanho do arquivo` `Status` `Hash criptográfico (identificador único)` ... entre outros, conforme a configuração do projeto.
