# Aba - Versões

A aba **Versões** permite acompanhar todo o histórico de alterações realizadas no objeto, garantindo rastreabilidade, transparência e controle sobre as modificações efetuadas ao longo do seu ciclo de vida.

Cada alteração registrada gera uma nova versão, permitindo consultar quando a modificação ocorreu, quem a realizou e quais informações foram alteradas.

{% hint style="info" %}
Nem todos os usuários possuem permissão para visualizar ou restaurar versões. Em caso de dúvidas, entre em contato com o gerente de projeto ou suporte da equipe SOS Docs.
{% endhint %}

📌 **Informações disponíveis na aba:**

{% columns %}
{% column %}
* **Versão:** número sequencial de controle da versão do documento.
* **Operações:** tipo de ação realizada, como `UPDATE`, indicando que houve uma modificação.
* **Responsável:** quem foi o responsável direto pela ação.
* **Data:** data em que a versão foi registrada no sistema.
{% endcolumn %}

{% column %}
* **Usuário:** nome ou e-mail do usuário que realizou a modificação.
* **🔍 Ícone de lupa:** Ao clicar no ícone de **lupa**, o sistema exibe uma ficha detalhada com os metadados completos do documento naquela versão específica e o comparativo com versões anteriores.
{% endcolumn %}
{% endcolumns %}

{% hint style="info" %}
🧠 **Você sabia?**

No DocZ, quando você **versiona** um arquivo, os **metadados de todas as versões** são preservados para garantir rastreabilidade. As versões anteriores não ficam visíveis para o usuário logado, mas podem ser acessadas diretamente no repositório técnico — nesse caso, é necessário acionar o **suporte do grupo SOSDocs**.

Já ao **substituir**, apenas o arquivo mais recente permanece disponível na interface do usuário, sem manter as versões anteriores para consulta.

👉 Em resumo: **versionar = histórico técnico** | **substituir = manter só a versão atual**.
{% endhint %}

***

#### **Comparação entre versões**

Ao clicar no ícone de **lupa**, o sistema exibe um comparativo detalhado entre a versão selecionada e a versão atual do objeto.

Nessa visualização é possível identificar exatamente quais metadados foram alterados, facilitando auditorias, validações e análises de alterações realizadas ao longo do tempo.

Os campos que sofreram modificações são destacados visualmente pelo sistema, permitindo localizar rapidamente as diferenças entre as versões comparadas.

**Controle de rastreabilidade**

O histórico de versões é utilizado para registrar alterações realizadas manualmente pelos usuários e também modificações executadas automaticamente pelo sistema, como processos de reclassificação, atualização de temporalidade e recálculo de prazos documentais.

> Importante: o versionamento preserva o histórico das informações do objeto, permitindo consultar alterações realizadas ao longo do tempo e garantindo conformidade com requisitos de auditoria e rastreabilidade documental.
