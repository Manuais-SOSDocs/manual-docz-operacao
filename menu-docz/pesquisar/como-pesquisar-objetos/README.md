# Como pesquisar objetos?

### Para localizar caixas ou documentos no sistema DocZ, siga os passos abaixo:

{% stepper %}
{% step %}
#### Acessando a Tela de Pesquisa

* No **módulo de Projeto** do menu, selecione o projeto em que deseja procurar o objeto. **(Se o cliente tiver apenas um projeto, essa seleção não será necessária).**
* Clique no ícone da **lupa** para ser direcionado à tela de pesquisa.

<figure><img src="../../../.gitbook/assets/© 2025 SOS Docs  Todos os direitos reservados. (1280 x 500 px) (3).gif" alt=""><figcaption></figcaption></figure>

* Se o cliente tiver apenas um projeto cadastrado, você também pode acessar a pesquisa diretamente pelo menu lateral em **Pesquisar**.

<figure><img src="../../../.gitbook/assets/image (62).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
#### Estrutura da Tela de Pesquisa

A tela de pesquisa é dividida em dois blocos principais:

<figure><img src="../../../.gitbook/assets/image (63).png" alt=""><figcaption></figcaption></figure>

<table data-card-size="large" data-view="cards"><thead><tr><th></th></tr></thead><tbody><tr><td><p><strong>Bloco esquerdo – Repositório:</strong></p><div><figure><img src="../../../.gitbook/assets/image (65).png" alt=""><figcaption></figcaption></figure></div><ul><li>Aqui você escolhe a pasta em que deseja buscar os objetos.</li><li>Você pode optar por pesquisar apenas <strong>caixas</strong> ou apenas <strong>documentos</strong>.</li><li><p><mark style="color:blue;"><strong>Para selecionar a pasta:</strong></mark></p><ul><li>Clique duas vezes sobre a pasta desejada;</li><li>Ou clique com o botão direito sobre a pasta e selecione <strong>🔍 Pesquisar</strong>.</li></ul><div><figure><img src="https://manualsosdocs.gitbook.io/~gitbook/image?url=https%3A%2F%2F4270511437-files.gitbook.io%2F%7E%2Ffiles%2Fv0%2Fb%2Fgitbook-x-prod.appspot.com%2Fo%2Fspaces%252FTOkpktW1KcGIR73wpKDq%252Fuploads%252FeZuPO2Br1M5U0duP7XFI%252Fimage.png%3Falt%3Dmedia%26token%3D2d391ab0-f2ec-406e-9625-79794588abdd&#x26;width=768&#x26;dpr=4&#x26;quality=100&#x26;sign=d2ff9a38&#x26;sv=2" alt="" width="563"><figcaption></figcaption></figure></div><p></p></li></ul><p>           <a href="mais-acoes-nas-pastas-do-repositorios.md" class="button primary" data-icon="plus-large">Mais ações no repositório</a></p></td></tr><tr><td><p><strong>Bloco direito – Filtros:</strong></p><div><figure><img src="../../../.gitbook/assets/image (66).png" alt=""><figcaption></figcaption></figure></div><p>Inicialmente, o título exibido corresponde ao <strong>nome do projeto</strong>.<br>Ao selecionar uma pasta, o título será atualizado para o <strong>nome da pasta</strong> escolhida (caixas ou documentos).</p><p></p><p>Para aprender a aplicar os filtros, <a href="./#descubra-como-aplicar-filtros-de-pesquisa-no-docz"><strong>clique aqui</strong>.</a><br><br><br><br><br></p></td></tr></tbody></table>
