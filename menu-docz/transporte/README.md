# TRANSPORTE

O módulo **Transporte** é responsável pelo gerenciamento logístico das movimentações físicas realizadas pela operação documental. Ele permite controlar os veículos utilizados nos atendimentos, os responsáveis pelas entregas e coletas, além do acompanhamento dos transportes vinculados às Ordens de Serviço (OS).
