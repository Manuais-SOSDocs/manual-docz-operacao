# Central de Downloads

A tela **Central de Downloads** permite que o usuário localize e baixe relatórios que foram gerados em segundo plano pelo sistema.

{% hint style="info" %}
O processamento em segundo plano garante que relatórios mais pesados ou complexos sejam gerados sem interromper o uso do sistema, permitindo que o usuário continue suas atividades normalmente enquanto o relatório é preparado.
{% endhint %}

<figure><img src="../../.gitbook/assets/image (331).png" alt=""><figcaption></figcaption></figure>

#### 📥 Como utilizar a Central de Downloads

{% stepper %}
{% step %}
Acesse a tela "Central de Downloads" no <kbd>menu</kbd> > <kbd>Central de Downloads</kbd> .
{% endstep %}

{% step %}
Na grid "Filtro Relatórios", aplique os filtros conforme a necessidade:

<table><thead><tr><th width="109">Filtro</th><th>Descrição</th><th>Quando utilizar</th></tr></thead><tbody><tr><td><mark style="color:$primary;"><strong>Data Inicial</strong></mark></td><td>Define a data de início do período que será pesquisado. O sistema retornará apenas os arquivos gerados a partir desta data.</td><td>Quando for necessário localizar relatórios gerados em um período específico.</td></tr><tr><td><mark style="color:$primary;"><strong>Data Final</strong></mark></td><td>Define a data final do período pesquisado. É utilizada em conjunto com a Data Inicial para delimitar um intervalo de busca.</td><td>Para restringir a pesquisa a um período determinado.</td></tr><tr><td><mark style="color:$primary;"><strong>Projetos</strong></mark></td><td>Permite filtrar os arquivos gerados por um projeto específico.</td><td>Quando o usuário possui acesso a vários projetos e deseja visualizar apenas os downloads relacionados a um deles.</td></tr><tr><td><mark style="color:$primary;"><strong>Status do Relatório</strong></mark></td><td>Filtra os relatórios conforme seu estado de processamento. Dependendo da configuração do ambiente, podem existir status como <em>Processando</em>, <em>Concluído</em>, <em>Erro</em> ou equivalentes.</td><td>Para verificar se um relatório já foi finalizado ou identificar falhas na geração.</td></tr><tr><td><mark style="color:$primary;"><strong>Usuário Solicitante</strong></mark></td><td>Exibe apenas os arquivos gerados por um usuário específico.</td><td>Útil para auditoria, acompanhamento de atividades ou quando vários usuários compartilham o mesmo ambiente.</td></tr></tbody></table>
{% endstep %}

{% step %}
Clique no botão <img src="../../.gitbook/assets/image (617).png" alt="" data-size="line"> para buscar os relatórios com base nos critérios definidos.
{% endstep %}

{% step %}
Verifique os resultados na grid "Relatórios Disponíveis".
{% endstep %}

{% step %}
Selecione o relatório e clique em "Baixar Arquivo" ao lado do relatório desejado para realizar o download.

<figure><img src="../../.gitbook/assets/image (618).png" alt=""><figcaption></figcaption></figure>
{% endstep %}
{% endstepper %}

**Download iniciado no desktop.**
