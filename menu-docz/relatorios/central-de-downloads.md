# Central de Downloads

A tela **Central de Downloads** permite que o usuário localize e baixe relatórios que foram gerados em segundo plano pelo sistema.

{% hint style="info" %}
O processamento em segundo plano garante que relatórios mais pesados ou complexos sejam gerados sem interromper o uso do sistema, permitindo que o usuário continue suas atividades normalmente enquanto o relatório é preparado.
{% endhint %}

<figure><img src="../../.gitbook/assets/image (331).png" alt=""><figcaption></figcaption></figure>

### 📥 Como utilizar a Central de Downloads

{% stepper %}
{% step %}
Acesse a tela "Central de Downloads" no <kbd>menu</kbd> > <kbd>Central de Downloads</kbd> .
{% endstep %}

{% step %}
Na grid "Filtro Relatórios", aplique os filtros conforme a necessidade:

<kbd>Data Inicial e Data Final</kbd>   <kbd>Projetos (campo obrigatório)</kbd>   \
<kbd>Status do Relatório</kbd>   <kbd>Usuário Solicitante</kbd>
{% endstep %}

{% step %}
Clique no botão  ![](<../../.gitbook/assets/image (333).png>)  para buscar os relatórios com base nos critérios definidos.
{% endstep %}

{% step %}
Verifique os resultados na grid "Relatórios Disponíveis".
{% endstep %}

{% step %}
Selecione o relatório e clique em "Baixar Arquivo" ao lado do relatório desejado para realizar o download.

<figure><img src="../../.gitbook/assets/image (332).png" alt=""><figcaption></figcaption></figure>
{% endstep %}
{% endstepper %}

{% hint style="success" %}
**Download iniciado no desktop.**
{% endhint %}
