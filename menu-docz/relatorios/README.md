# RELATÓRIOS

O módulo **Relatórios** reúne as funcionalidades responsáveis pela geração, consulta e exportação de informações operacionais e gerenciais do DocZ, permitindo acompanhar indicadores, atividades dos usuários, processos de indexação e dados relacionados aos clientes.

Os relatórios podem ser gerados a partir de diferentes filtros e critérios de pesquisa, facilitando auditorias, conferências e análises das informações registradas no sistema.

O módulo também disponibiliza a **Central de Downloads**, onde os usuários podem localizar e baixar relatórios gerados em segundo plano pelo DocZ, permitindo o acesso aos arquivos após a conclusão do processamento.
