# Relatórios Cliente

Esta tela permite gerar relatórios personalizados com base nas informações vinculadas a clientes e projetos, facilitando a análise e extração de dados conforme critérios definidos.

<figure><img src="../../.gitbook/assets/image (336).png" alt=""><figcaption></figcaption></figure>

<details>

<summary><strong>Quando utilizar este relatório?</strong></summary>

Este conjunto de relatórios é indicado para:

* Inventários documentais;
* Controle da movimentação do acervo;
* Monitoramento de empréstimos;
* Auditorias;
* Controle da temporalidade;
* Gestão de eliminação documental;
* Análise operacional e gerencial do acervo.

> **Importante:** Os relatórios de Expurgo Caixa e Expurgo Documento possuem relevância arquivística e jurídica, pois registram evidências das eliminações realizadas conforme as regras de temporalidade e destinação documental adotadas pela instituição.

</details>

#### 📌 **Passo a Passo para gerar um relatório:**

{% stepper %}
{% step %}
Escolha o cliente desejado na lista.
{% endstep %}

{% step %}
Após selecionar o cliente, defina o projeto correspondente.
{% endstep %}

{% step %}
Depois selecione o tipo de relatório a ser gerado.
{% endstep %}

{% step %}
Escolha se o filtro será feito com base na Data de Criação ou na Data da Categoria Complementar. (opcional)
{% endstep %}

{% step %}
Preencha os campos de _Data Inicial_ e _Data Final_ para filtrar os dados conforme o intervalo desejado.
{% endstep %}

{% step %}
Selecione a extensão desejada para o relatório: `.xls`, `.csv` ou `.pdf`.
{% endstep %}

{% step %}
Clique no botão <img src="../../.gitbook/assets/image (616).png" alt="" data-size="line"> .
{% endstep %}
{% endstepper %}

{% hint style="success" %}
**O download será iniciado automaticamente no desktop.**
{% endhint %}
