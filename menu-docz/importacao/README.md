# IMPORTAÇÃO

A funcionalidade de **Importação de Metadados** permite a inclusão ou atualização em massa de registros no DocZ, utilizando arquivos CSV ou XLSX, com rastreabilidade e aplicação automática de regras de classificação quando configuradas.

{% hint style="info" %}
O acesso à configuração de classificação automática é restrito a usuários com permissões específicas. Usuários sem essa autorização não visualizam nem acessam a funcionalidade.

Caso seja necessário, o acesso deve ser solicitado ao suporte.
{% endhint %}
