### Confira o que cada aba representa e como utilizá-la:

<details>

<summary>🔍 Acessando os Detalhes do Documento</summary>

1️⃣ Realize uma pesquisa e selecione o documento desejado.\
2️⃣ Clique no ícone **“Abrir”** ao lado do documento para visualizar os detalhes.

O sistema exibirá uma **tela pop-up** na aba **Detalhes**, onde é possível consultar os **metadados** atribuídos ao objeto, seja manualmente ou por leitura do fotolabel (OCR).

Nesta aba, no **canto superior esquerdo**, estão disponíveis as seguintes ações:

<figure><img src="../../../.gitbook/assets/image (51).png" alt=""><figcaption></figcaption></figure>

* **Editar metadados** (se você tiver permissão): clique no ícone de **disquete** para salvar as alterações.
* **Imprimir etiqueta**: clique no ícone de **impressora** para gerar a etiqueta do documento.

Os campos de metadados podem ser personalizados conforme as especificicações do projeto. Contudo, existem campos fixos, que incluem:

* **Identificador SOS**
* **Localização**
* **Status**
* **Departamento**
* **Descrição**
* **Tipo de Objeto**
* **Ano** (novo campo adicionado, útil para documentos que não possuem data completa)
* **Etapa de Indexação**
* **Classificação**
* **Fase Corrente**
* **Fase Intermediária**
* **Destinação Final**
* **Sigilo Associado**
* **Observações**

<figure><img src="https://manualsosdocs.gitbook.io/~gitbook/image?url=https%3A%2F%2F4270511437-files.gitbook.io%2F%7E%2Ffiles%2Fv0%2Fb%2Fgitbook-x-prod.appspot.com%2Fo%2Fspaces%252FTOkpktW1KcGIR73wpKDq%252Fuploads%252F2Rt1VBoaIPw1ABCP4Sl5%252Fimage.png%3Falt%3Dmedia%26token%3D8d6c8585-c26e-4bc5-8771-f14b0a3f95df&#x26;width=768&#x26;dpr=4&#x26;quality=100&#x26;sign=3aad3ffe&#x26;sv=2" alt=""><figcaption></figcaption></figure>

<summary>🔗 <strong>Relações entre Documentos</strong></summary>

_Visualize documentos que compartilham informações em comum e navegue entre eles com facilidade._

<summary>📑 <strong>Controle de Versões</strong></summary>

A aba **Versões** permite acompanhar todo o histórico de alterações realizadas em um documento, garantindo **transparência**, **controle de edição** e **rastreabilidade** das mudanças feitas ao longo do tempo.

📌 **Informações disponíveis na aba:**

* **Versão:** número sequencial de controle da versão do documento.
* **Operações:** tipo de ação realizada, como `UPDATE`, indicando que houve uma modificação.
* **Responsável:** quem foi o responsável direto pela ação.
* **Data:** data em que a versão foi registrada no sistema.
* **Usuário:** nome ou e-mail do usuário que realizou a modificação.
* **🔍 Ícone de lupa:** Ao clicar no ícone de **lupa**, o sistema exibe uma ficha detalhada com os metadados completos do documento naquela versão específica.

<mark style="background-color:$success;">🧠</mark> <mark style="background-color:$success;"></mark><mark style="background-color:$success;">**Você sabia?**</mark>\ <mark style="background-color:$success;">No DocZ, quando você</mark> <mark style="background-color:$success;"></mark><mark style="background-color:$success;">**versiona**</mark> <mark style="background-color:$success;"></mark><mark style="background-color:$success;">um arquivo, os</mark> <mark style="background-color:$success;"></mark><mark style="background-color:$success;">**metadados de todas as versões**</mark> <mark style="background-color:$success;"></mark><mark style="background-color:$success;">são preservados para garantir rastreabilidade. As versões anteriores não ficam visíveis para o usuário logado, mas podem ser acessadas diretamente no repositório técnico — nesse caso, é necessário acionar o</mark> <mark style="background-color:$success;"></mark><mark style="background-color:$success;">**suporte do grupo SOSDocs**</mark><mark style="background-color:$success;">.</mark>

<mark style="background-color:$success;">Já ao</mark> <mark style="background-color:$success;"></mark><mark style="background-color:$success;">**substituir**</mark><mark style="background-color:$success;">, apenas o arquivo mais recente permanece disponível na interface do usuário, sem manter as versões anteriores para consulta.</mark>

<mark style="background-color:$success;">👉 Em resumo:</mark> <mark style="background-color:$success;"></mark><mark style="background-color:$success;">**versionar = histórico técnico**</mark> <mark style="background-color:$success;"></mark><mark style="background-color:$success;">|</mark> <mark style="background-color:$success;"></mark><mark style="background-color:$success;">**substituir = manter só a versão atual**</mark><mark style="background-color:$success;">.</mark>
