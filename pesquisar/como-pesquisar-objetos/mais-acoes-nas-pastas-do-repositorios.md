No repositório de pastas, você pode gerenciar caixas e documentos de forma prática.\
Basta clicar com o **botão direito** sobre uma pasta para ver as opções disponíveis, como:

<summary><strong>Detalhar</strong></summary>

A funcionalidade **Detalhar** permite que o usuário **visualize as informações completas de uma pasta dentro do projeto**.

Ao selecionar essa opção, será aberta, **no lado direito da tela**, uma aba com os principais dados da pasta, como:

* **Dados**
* **Status**
* **Tipo de objeto**

Essa visualização ajuda o usuário a **consultar rapidamente informações importantes**, sem precisar abrir ou editar a pasta.

<summary>Navegar por Fotolabel</summary>

A funcionalidade **Navegar por Fotolabel** permite que o usuário visualize **todas as fotolabels das caixas de um projeto ao mesmo tempo**, facilitando o controle de qualidade sem a necessidade de abrir caixa por caixa no repositório de documentos.

Essa opção está disponível **somente para usuários com a permissão “Navegar por Fotolabel”** ativa no sistema.

#### 🚀 Como acessar

Siga os passos abaixo para visualizar todas as fotolabels das caixas de um projeto:

1. **Acesse**, no lado esquerdo da tela, as **pastas do projeto**.
2. Localize a pasta desejada e **clique com o botão direito** para abrir o menu de opções.
3. No menu que aparece, selecione **“Navegar por Fotolabel”**.
4. O sistema abrirá uma **nova guia** com a interface de navegação das fotolabels.

<summary>Inserir documento</summary>

A funcionalidade **Inserir documento** permite que o usuário **cadastre novos documentos dentro do projeto**, adicionando-as diretamente ao repositório do sistema.

#### 🚀 Como acessar

Siga os passos abaixo para inserir uma nova caixa em um projeto:

1. **Acesse**, no lado esquerdo da tela, as **pastas do projeto**.
2. Localize a pasta desejada e **clique com o botão direito** para abrir o menu de opções.
3. No menu que aparece, selecione **“Inserir documento”**.
4. O sistema abrirá uma **pop-up** com o **formulário de indexação do documento**.
   * O campo **ID SOS** será gerado automaticamente e **não pode ser alterado**.
5. **Preencha as informações necessárias** nos campos do formulário.
6. Clique no **ícone do disquete 💾** para **salvar**.

<summary>Inserir caixa</summary>

A funcionalidade **Inserir Caixa** permite que o usuário **cadastre novas caixas dentro do projeto**, adicionando-as diretamente ao repositório do sistema.

#### 🚀 Como acessar

Siga os passos abaixo para inserir uma nova caixa em um projeto:

1. **Acesse**, no lado esquerdo da tela, as **pastas do projeto**.
2. Localize a pasta desejada e **clique com o botão direito** para abrir o menu de opções.
3. No menu que aparece, selecione **“Inserir caixa”**.
4. O sistema abrirá uma **pop-up** com o **formulário de indexação da caixa**.
   * O campo **IDSOS** será gerado automaticamente e **não pode ser alterado**.
5. **Preencha as informações necessárias** nos campos do formulário.
6. Clique no **ícone do disquete 💾** para **salvar**.
7. Após salvar, **feche a pop-up.**

<summary>Editar</summary>

A funcionalidade **Editar** permite que o usuário **modifique os dados de uma pasta selecionada**, como **nome** e **código**, atualizando essas informações **diretamente no repositório do sistema**.

{% hint style="info" %}
Agora, os **objetos** (documentos e caixas) também podem ser **organizados pelo código alternativo do cliente**, oferecendo **mais flexibilidade no uso do DocZ** e **maior integração com sistemas externos via API**.
{% endhint %}

<summary>Mover</summary>

A funcionalidade **Mover** permite que o usuário **transfira uma pasta selecionada para dentro de outra pasta**, diretamente no **repositório do sistema**.

Dessa forma, é possível **organizar e realocar pastas** conforme a **parametrização definida no projeto**, mantendo a estrutura do repositório sempre atualizada.
